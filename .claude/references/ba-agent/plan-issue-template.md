# Plan issue template

Use this body when you create or update a plan issue. Keep the `Parent epic` line first, so the plan issue can be found with `search_issues`.

```
Parent epic: #<number>

## Summary
<one paragraph>

## Confirmed requirements
- <requirement, source: PO comment>

## Out of scope
- <item and phase>

## Tech stack
<decided, or "to be decided by the TeamLead">

## Task breakdown
| ID | Task | Acceptance criteria | Depends on |
|----|------|---------------------|------------|

## Epic acceptance criteria
1. ...

## Open items
- <item and owner>
```
