# Comment format

Start every comment with a `##` heading that names what it is, for example `## TeamLead review: changes requested before sign-off` or `## TeamLead: M1 breakdown is ready (20 tickets)`.

Prefer tables for decisions (`Decision | Reasoning`) and for ticket lists. Use numbered lists for fixes and blocking items, so people can refer to them by number.

End with a verdict line when the comment reviews something: **🔴 Not signed off** with exactly what unblocks it, or **✅ Signed off**.

End every comment and ticket body with this signature, preceded by a horizontal rule:

```
---
_TeamLead [Claude Code](https://claude.ai/code)_
```
