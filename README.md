# My Portfolio — Claude Training Practice

A practice repository for a Claude training course. The goal is to apply Claude across the full delivery lifecycle — **kick-off, planning, build, review, and test** — starting from a deliberately **vague customer request**.

## Objectives

- Turn an ambiguous customer request into clear, testable requirements.
- Use Claude as a collaborator at every stage of delivery.
- Capture prompts, decisions, and lessons learned along the way.

## Workflow

| Stage | What we do with Claude | Output |
|-------|------------------------|--------|
| 1. Kick-off | Clarify the vague request: ask questions, surface assumptions, risks and open items | Clarified brief, question list |
| 2. Planning | Break down scope, define user stories, acceptance criteria, milestones | Plan / backlog |
| 3. Build | Implement incrementally with Claude Code, small steps, test-first where practical | Working code |
| 4. Review | Code review, security and simplification passes | Review notes, fixes |
| 5. Test | Generate and run unit/e2e tests, verify against acceptance criteria | Test suite, results |
